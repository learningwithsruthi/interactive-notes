L1What a function actually is

You met the definition in 8th grade and used it in Unit 1. Math 1 sharpens it and gives the pieces names.

A function from a set called the domain to a set called the range assigns to each element of the domain exactly one element of the range.

Two consequences worth stating explicitly:

$f(x)$
the output of $f$ corresponding to the input $x$. Not $f$ multiplied by $x$.
The graph of $f$
is the graph of the equation $y = f(x)$. So a point $(a, b)$ is on the graph exactly when $f(a) = b$.
The vertical line test is a symptom, not the definition The test works because a vertical line collects every point sharing one input — two crossings means one input with two outputs. But plenty of functions are not graphs at all. NC explicitly asks about categorical situations, where there is nothing to draw.
A business keeps customer records.
Rule $C$ assigns each customer their home phone number. This is a function. Every customer has exactly one home number.
Rule $P$ assigns each phone number the customer name or names attached to it. Not a function. Two people in the same household share a number, so that one input returns two outputs.
Which is why a business identifies customers by something guaranteed unique, like an account number. Uniqueness of the input is what makes lookup reliable.
Drill — is this rule a function?

L2Function notation, and how to read it out loud

Evaluating is the easy half: substitute and compute.

Find $f(2)$ for $f(x) = 5(x - 3) + 17$:  $5(2-3) + 17 = 5(-1) + 17 = 12$
For $f(x) = 1200(1.04)^x$:  $1200(1.04)^2 = 1200(1.0816) = 1297.92$
For $f(x) = 3x^2 + 2x - 5$:  $3(4) + 2(2) - 5 = 11$

The harder half is reading a statement in function notation and saying what it means about the situation. That is what gets assessed.

A yam goes into the oven and comes out after 45 minutes. Let $f$ be the function assigning each minute since it went in to the yam's temperature in °F.

$f(0) = 65$
When the yam went in, it was 65°F — room temperature.
$f(5) < f(10)$
It was cooler at 5 minutes than at 10 minutes, so it was heating up over that stretch.
$f(40) = f(45)$
Same temperature at 40 and 45 minutes — it had stopped getting hotter, having reached the oven's temperature.
$f(45) > f(60)$
Fifteen minutes after coming out it was cooler than when it came out. It cooled once removed.
Read the input as a moment, not a number $f(45)$ is not "45". It is "the temperature at 45 minutes". Every interpretation sentence should name what the input measures and what the output measures, or it will not earn the point.
Going backwards. Suppose $f$ is a function.
If $10 = f(-4)$, then $(-4, 10)$ is a point on the graph — input first, output second.
If $6$ is a solution of $f(w) = 1$, then $f(6) = 1$, so $(6, 1)$ is on the graph.
Interpret each statement. $f(x) = 50(0.85)^x$ gives the milligrams of a drug in the bloodstream $x$ hours after a dose. What do $f(0)$ and $f(4)$ mean, and what are they?
$f(0) = 50(0.85)^0 = 50$. At the moment of the dose there are 50 mg in the bloodstream — the initial dose.
$f(4) = 50(0.85)^4 \approx 26.1$. Four hours later about 26.1 mg remain.
The decay factor 0.85 means 15% of the drug clears each hour, so roughly half is gone after four hours.

L3Key features of a graph

This is the heart of the unit. Given a graph — any graph, equation or not — you should be able to name and interpret every one of these.

Turn features on and off, then read what each one means

The graph above is a drone's height above a launch ledge, in metres, over 13 seconds. Negative means below the ledge. Here is every feature, in the language of the situation:

y-intercept
the output when the input is 0 — here $(0, -3)$, so the drone started 3 m below the ledge
x-intercepts
where the output is 0, also called zeros — here $x = 2, 8, 12$, the moments it was level with the ledge
Increasing
intervals where the output rises as the input grows — the drone climbing
Decreasing
intervals where the output falls — the drone descending
Positive
intervals where the output is above zero — the drone above the ledge
Negative
intervals where the output is below zero — the drone below the ledge
Maximum
the highest output reached — 6 m, at 4 seconds
Minimum
the lowest output reached — $-4$ m, at 10 seconds
Intervals are described in x, values in y "Increasing on $0 < x < 4$" is right. "Increasing from $-3$ to 6" describes the outputs, which is a different sentence. Say where using inputs; say how much using outputs.

L4Increasing is not the same as positive

These two get merged more than any other pair in Math 1, and the graph above contains both counterexamples.

Increasing / decreasing

About direction — is the graph going up or down as you read left to right?

Answers the question "is it growing?"

Compare each output to the previous output.

Positive / negative

About location — is the graph above or below the x-axis?

Answers the question "is the value more than zero?"

Compare each output to zero.

Increasing but negative: on $10 < x < 12$ the drone is climbing from $-4$ m back toward the ledge. Going up, still below zero.

Decreasing but positive: on $4 < x < 8$ the drone is descending from 6 m toward the ledge. Going down, still above zero.

A table can lie by omission A table only shows the rows someone chose to include. If it lists $x = 0, 1, 2, 3$ with outputs 5, 3, 3, 5, it looks like the minimum is 3 — but the real minimum sits somewhere between $x = 1$ and $x = 2$ and is never shown. Say "the smallest value in the table", not "the minimum", unless you can see the whole graph.
From an equation. For $f(x) = 2x - 10$, find the y-intercept, the x-intercept, and say where the function is positive.
y-intercept: $f(0) = -10$, so $(0, -10)$.
x-intercept: $2x - 10 = 0 \Rightarrow x = 5$, so $(5, 0)$.
Positive where $2x - 10 > 0$, that is $x > 5$. Negative for $x < 5$.
Increasing everywhere, since the rate of change 2 is positive — note it is increasing even on the stretch where it is still negative.

L6Building a function by combining functions

Sometimes the quantity you want is the difference, sum, or product of two things you can already model. You build each piece, then combine.

Two phone plans. Company Y charges a \$10 start-up fee plus \$0.10 per minute. Company Z charges \$0.20 per minute with no fee.
Model each: $Y(x) = 10 + 0.10x$ and $Z(x) = 0.20x$.
The difference: $D(x) = Y(x) - Z(x) = 10 + 0.10x - 0.20x = 10 - 0.10x$
Now read it. $D(0) = 10$: with no calls, Y costs \$10 more. $D(100) = 0$: at 100 minutes they cost the same. $D(200) = -10$: at 200 minutes Y is \$10 cheaper.
The zero of the difference function is the break-even point. That is usually the question being asked.
Two clearance strategies on a \$45 item
Write the difference function for the clearance options: Option 1 cuts the price 15% each week, Option 2 cuts it \$5 each week. The item starts at \$45.
Option 1 is exponential: $A(w) = 45(0.85)^w$.
Option 2 is linear: $B(w) = 45 - 5w$.
Difference: $D(w) = 45(0.85)^w - (45 - 5w)$.
$D$ is negative for the first five weeks — the percent-off price is lower. From week 6 on it turns positive, meaning the dollar-off price is lower.
And they behave completely differently at the end: the dollar-off option reaches \$0 at week 9, while the percent-off option never reaches \$0 at all.
Multiplying two linear functions. A rectangular cage floor has length 4 feet greater than its width $w$. Both dimensions are increased by 2 feet. Write the new area $N$.
Original: width $w$, length $w + 4$.
After the increase: width $w + 2$, length $w + 6$.
$N = (w + 6)(w + 2) = w^2 + 8w + 12$
Two linear functions multiplied gave a quadratic. That is where Unit 6 begins.

✓Quick review

Function
each element of the domain is assigned exactly one element of the range
$f(x)$
the output for input $x$; the point $(a,b)$ is on the graph exactly when $f(a) = b$
Intercepts
y-intercept at $x = 0$; x-intercepts (zeros) where the output is 0
Increasing
the output rises as the input grows — about direction
Positive
the output is above zero — about location. Not the same thing.
Max / min
the highest and lowest outputs; report both the value and where it happens
Combining
add or subtract functions to model a difference; the zero of a difference function is the break-even point

If you remember one thing: every feature has a meaning in the situation. Naming the feature is half the answer; saying what it means about the drone, the drug, or the phone bill is the other half, and it is the half that gets marked.
