The sentence that holds this unit together: arithmetic sequences belong to the linear family of functions, and geometric sequences belong to the exponential family. Everything else in Unit 2 is working out what that means.

KeyThe tie-back: your sequences were functions

In Unit 1 you wrote $a_n = a_1 + d(n-1)$ and $a_n = a_1 \cdot r^{\,n-1}$ and only ever asked for positions 1, 2, 3, and so on. That restriction was the only thing separating those objects from the two function families this unit is named after.

Concretely: the sequence 3, 7, 11, 15, … from Unit 1.
As a sequence: $a_n = 3 + 4(n-1) = 4n - 1$, and $a_{2.5}$ is a meaningless question.
As a linear function: $f(x) = 4x - 1$, and $f(2.5) = 9$ is a perfectly good answer.
Same rule, wider door. The sequence is the function sampled at whole numbers; the function is the sequence with the gaps filled in.
Where the $n-1$ went Sequences start counting at position 1, so the formula steps back once to reach the intercept. Functions start at $x = 0$, where the intercept simply is the starting value. That is the whole reason $a_n = a_1 + d(n-1)$ becomes $f(x) = mx + b$ with no $-1$ in sight. Same line, different starting post.

L3The defining characteristic of each family

Now that the inputs can be any number, the Unit 1 tests need restating. "Subtract neighbours" assumed the neighbours were one position apart. The grown-up version:

Linear functions

Grow by equal differences over equal intervals.

Step forward by the same amount in $x$, and $y$ always changes by the same amount.

Test: subtract. The differences are constant.

Family member from Unit 1: arithmetic sequences.

Exponential functions

Grow by equal factors over equal intervals.

Step forward by the same amount in $x$, and $y$ is always multiplied by the same amount.

Test: divide. The ratios are constant.

Family member from Unit 1: geometric sequences.

The phrase "over equal intervals" is doing real work. It means the test still applies when the inputs step by 2, or by 0.5, or by anything else — as long as the step is consistent.

Change the input step and watch both tests stay valid
A trap the wider inputs create With whole-number positions, "the ratio between neighbours" was unambiguous. With any real input it is not — a function can look like it has a constant ratio if you only sample it at convenient places. Always check that your inputs are equally spaced before trusting either test.

L1Four situations, two questions

Two independent questions decide how you model a situation, and they are easy to conflate:

Adding or multiplying?
a fixed amount each step means the linear family; a fixed percent or factor means the exponential family
Can the input be a fraction?
if yes the model is continuous; if it only makes sense at whole steps it is discrete

Those two questions are independent, which gives four combinations. All four are real.

Compare the piggy bank and the bank account. What is the same and what is different?
Same: both are discrete — the amount only changes at whole-numbered moments, so both graph as separate dots. Both start small and grow.
Different: the piggy bank adds a fixed 3 pennies (arithmetic, linear family). The account multiplies by 1.03 (geometric, exponential family). Early on the piggy bank is well ahead; eventually the account overtakes it, because multiplying always beats adding in the long run.
Compare the two pools. Both are continuous, so what separates them?
Filling adds a fixed 2 gallons every minute regardless of how much is in there, so it is linear and the graph is a straight line.
Draining removes 3% of what remains, so the amount lost shrinks as the pool empties. That is exponential decay and the graph is a curve flattening out.
When is the draining pool empty?
Never, according to the model. $1500(0.97)^t$ gets arbitrarily close to zero but never reaches it — taking 3% of a positive number always leaves a positive number.
After 100 minutes about 71 gallons remain; after 200 minutes about 3.4 gallons; after 500 minutes about 0.0004 gallons.
In reality the pool does empty. This is a model breaking down at the edges, and saying so is the correct answer.

L2Discrete or continuous, and how to decide

The deciding question is about the domain — the set of inputs the situation actually allows.

The test that settles it: pick a value between two of your inputs and ask whether it means anything. If there can genuinely be a moment when 32.5 books have been shipped, the model is continuous. If books arrive only in whole boxes, it is discrete.

Drill — discrete or continuous?
The two questions people merge Discrete does not mean arithmetic, and continuous does not mean exponential. The paper-cutting pattern (1, 3, 9, 27 pieces) is geometric and discrete — you cannot make half a cut. A filling pool is linear and continuous. Decide the two questions separately, every time.

Answering the Learning Focus questions this lesson poses directly:

Are all linear functions continuous?
No. The function $f(x) = mx + b$ is continuous, but a linear model of a discrete situation is not — the piggy bank uses a linear rule on a whole-number domain.
Are all arithmetic sequences discrete?
Yes. A sequence's domain is positions, which are whole numbers by definition.
Are all geometric sequences discrete?
Yes, for the same reason.
Are all exponential functions continuous?
The function itself is, but again an exponential model can sit on a discrete domain, like interest paid only at month end.

%Growth factors and percents

In $f(x) = a \cdot b^{\,x}$, the $a$ is the starting value and the $b$ is the growth factor — what you multiply by each step. Translating a percent into a growth factor is where most errors happen.

Growth: up $p$ percent means $b = 1 + \dfrac{p}{100}$.   Up 3% gives $b = 1.03$.

Decay: down $p$ percent means $b = 1 - \dfrac{p}{100}$.   Down 3% gives $b = 0.97$.

$b > 1$
growth — the curve rises
$0 < b < 1$
decay — the curve falls toward zero
$b = 1$
no change — a flat line
The mistake to inoculate against A 3% decrease does not give $b = 0.03$. You keep 97%, so $b = 0.97$. Writing $b = 1 - 0.03$ every single time makes this automatic. Using $b = 0.03$ would mean losing 97% per step, which is a wildly different situation.
Write the function. A town of 12,000 people grows 2.5% per year. What is the population after 10 years?
$b = 1 + 0.025 = 1.025$, so $P(t) = 12000(1.025)^t$.
$P(10) = 12000(1.025)^{10} \approx 15{,}361$ people.
Write the function. A \$28,000 car loses 15% of its value each year. What is it worth after 6 years?
$b = 1 - 0.15 = 0.85$, so $V(t) = 28000(0.85)^t$.
$V(6) = 28000(0.85)^6 \approx \$10{,}560$.

L4Negative exponents and what the graph does

The exponent rules from 8th grade are not just algebra housekeeping here — they explain the shape of an exponential graph, particularly the part to the left of the y-axis.

Look at $f(x) = 2^x$ for negative inputs. The graph hugs the x-axis without ever touching it, and the exponent rules say exactly why:

$2^{-1} = \dfrac{1}{2^1} = 0.5$
$2^{-2} = \dfrac{1}{2^2} = 0.25$
$2^{-5} = \dfrac{1}{32} = 0.03125$
$2^{-10} = \dfrac{1}{1024} \approx 0.00098$
The pattern: a negative exponent gives a reciprocal, and reciprocals of huge numbers are tiny positive numbers. Tiny but never zero — which is why the curve approaches the x-axis forever and never crosses it.
Exponential explorer — watch the left tail
2

That flat line the curve chases is called a horizontal asymptote. For $f(x) = a \cdot b^{\,x}$ it sits at $y = 0$. An exponential function never outputs zero, no matter how far you go.

And $b^0 = 1$ is why every one of these curves passes through $(0, a)$ — the same fact that made $a_1 \cdot r^0 = a_1$ produce the correct first term back in Unit 1.

L5Which model fits this situation?

Given a described situation and no numbers at all, you should be able to say which family it belongs to and defend the choice. The whole argument rests on one question: is the change a fixed amount, or a fixed share of what is already there?

Linear if the quantity changes by the same amount each period. Look for words like "per", "each", "every" attached to a fixed number of things.

Exponential if it changes by the same percent or fraction each period. Look for percentages, "doubles", "halves", "of what remains".

The classic contrast: two towns each have 145 residents. Town A adds 10 people a year. Town B grows 10% a year.
Town A: a fixed 10 people regardless of size. Linear. $A(t) = 145 + 10t$.
Town B: 10% of the current population, which is a bigger number every year. Exponential. $B(t) = 145(1.10)^t$.
Year 1: A has 155, B has 159.5 — B is already ahead, because 10% of 145 is more than 10.
Year 20: A has 345, B has about 975. The gap is not close.
Drill — linear or exponential?

ARCAverage rate of change

Slope only makes sense for a straight line. For any function — curve included — the equivalent idea is the average rate of change over a chosen interval.

Over the interval $a \le x \le b$: $$\text{average rate of change} = \frac{\Delta y}{\Delta x} = \frac{f(b) - f(a)}{b - a}$$

It is the slope of the straight line joining the two endpoints of that interval, and it answers "on average, how fast did this change across that stretch?"

The result is the sharpest test yet for telling the families apart:

Linear

The average rate of change is the same over every interval, and it always equals the slope.

For $f(x) = 3x - 7$ it is 3 over $[1,5]$, over $[0,1]$, over $[10,20]$ — always 3.

Exponential

The average rate of change keeps growing. It depends entirely on which interval you pick.

For $h(x) = 3(2)^x$ it is 6 over $[1,2]$ but 48 over $[4,5]$.

Reading it from a table. Temperature in Tucson, $t$ hours after midnight: at $t=0$ it is 85°F, at $t=3$ it is 76°F, at $t=4$ it is 70°F. When is the temperature falling fastest — between midnight and 3am, or between 3am and 4am?
Midnight to 3am: $\dfrac{76 - 85}{3 - 0} = \dfrac{-9}{3} = -3$ degrees per hour.
3am to 4am: $\dfrac{70 - 76}{4 - 3} = \dfrac{-6}{1} = -6$ degrees per hour.
It falls twice as fast between 3 and 4am.
The total drop from midnight to 3am is larger (9 degrees vs 6), but it is spread over three hours. Rate is change divided by time, not change alone.
Find the average rate of change over $1 \le x \le 5$ for $f(x) = 3x - 7$ and for $h(x) = 3(2)^x$.
$f$:  $f(1) = -4$, $f(5) = 8$, so $\dfrac{8 - (-4)}{4} = 3$. Same as its slope, as it must be.
$h$:  $h(1) = 6$, $h(5) = 96$, so $\dfrac{96 - 6}{4} = 22.5$.
The 22.5 describes only that stretch. Over $[5,9]$ the same function averages 360.

vsLinear against exponential, in the long run

A question this unit returns to repeatedly: given a head start, can a linear function stay ahead of an exponential one?

For a while, easily. Forever, never.

Give the linear function any head start you like
25

Any exponential with $b > 1$ eventually exceeds any linear function, whatever head start the linear one gets. The crossover can be pushed far to the right, but it always arrives.

The problem that makes the point: Kevin and Joseph each invest \$100. Kevin's account earns a flat \$5 every month. Joseph's earns 3% interest every month.
(a) Who has more after two years? At 24 months Kevin has $100 + 5(24) = \$220$. Joseph has $100(1.03)^{24} \approx \$203.28$. Kevin is ahead — which surprises people who have been told exponentials always win.
(b) When do they tie? Month 32: Kevin \$260, Joseph \$257.51. Month 33: Kevin \$265, Joseph \$265.23. Joseph passes him during month 33.
(c) And afterwards? The gap only widens. At 5 years Kevin has \$400 and Joseph has about \$589.
"Eventually" is doing real work in that sentence Exponential growth beats linear growth in the long run, not immediately. For the first 32 months the flat \$5 was the better deal. Any claim about which model is bigger has to name a time frame, and questions in this unit are often built to catch the assumption that exponential wins from the start.

End behaviour

The formal way to describe "in the long run" is end behaviour — what a function does as the input grows without bound. The notation is $x \to \infty$, read "as $x$ goes to infinity".

Linear, $m > 0$
as $x \to \infty$, $f(x) \to \infty$ — rising steadily, at a fixed rate forever
Exponential, $b > 1$
as $x \to \infty$, $f(x) \to \infty$ — also rising, but the rate itself keeps increasing
Exponential, $0 < b < 1$
as $x \to \infty$, $f(x) \to 0$ — falling toward the asymptote, never reaching it

Both growing families head to infinity, so "which is bigger at the end" cannot be settled by end behaviour alone. It is settled by the average rate of change: an exponential's keeps climbing, so it eventually overtakes any fixed rate. Unit 6 adds quadratics to this comparison, and exponentials outgrow those too.

a,bReading the parameters in context

Once a function models something real, every symbol in it means something real. Being asked "what does the 1.04 represent?" is a standard question, and the answer is never "the growth factor" on its own — it has to be said in the language of the situation.

Linear: $f(x) = ax + b$

$a$ is the constant rate of change — how much the quantity moves per unit.

$b$ is the initial value — the amount before anything happens.

Exponential: $g(x) = a \cdot b^{\,x}$

$a$ is the initial value — the amount at $x = 0$.

$b$ is the growth or decay factor — what you multiply by each period.

Factor and rate are not the same number A factor of 0.85 means a decay rate of 15%. A factor of 1.05 means a growth rate of 5%. If a question asks for the rate, subtract 1 from the factor and convert to a percent; do not hand back the factor.
A plumber charges \$50 for the house call plus \$85 an hour: $y = 85x + 50$.
Raise the hourly rate to \$90: $y = 90x + 50$. Only $a$ changes — the call-out fee is unaffected, so the graph keeps the same intercept and gets steeper.
Raise the call-out fee instead: only $b$ changes — the line shifts up without changing steepness.
1. $y = 8000(1.04)^x$ models a city of 8,000 growing 4% a year. (a) What changes if the city starts at 12,000 instead? (b) What if the growth rate were 6% instead of 4% — how different is the population after 25 years?
(a) Only the initial value changes: $y = 12000(1.04)^x$. The shape of the curve is identical, just started higher.
(b) $y = 8000(1.06)^x$. After 25 years: at 4% the city reaches about 21,327; at 6% about 34,335.
Two percentage points of growth rate produced roughly 13,000 extra people. Changing $b$ has a far bigger long-run effect than changing $a$, because $b$ is applied over and over.
2. $f(n) = P(1 + r)^n$ models a savings account earning 8% compounded annually, $n$ years after the deposit. (a) What is $r$ and what does it mean? (b) What does $P$ mean? (c) Will $n$ or $f(n)$ ever equal 0?
(a) $r = 0.08$, the annual interest rate. The growth factor is $1 + r = 1.08$.
(b) $P$ is the principal — the amount deposited at the start. It is the value when $n = 0$, since $(1.08)^0 = 1$.
(c) $n = 0$ is fine: that is the moment of deposit. But $f(n)$ is never 0 — multiplying a positive principal by 1.08 repeatedly can never produce zero. That is the horizontal asymptote again.

D&RDomain and range in context

A function written on its own usually accepts any input. The moment it models a situation, reality starts refusing inputs, and saying which ones is part of the answer.

Take the draining pool: $g(t) = 1500(0.97)^t$.
Mathematically $t$ can be any real number — including $t = -20$, which the algebra handles happily.
In context $t$ cannot be negative, because there was no draining before it started. The domain is $t \ge 0$.
The range in context runs from just above 0 up to 1500 gallons — it never reaches 0, and it never exceeds what the pool held.

Three restrictions come up again and again:

No negative time
most models start at $t = 0$, so the domain begins there
No fractional counts
people, boxes, and cuts are whole numbers, which makes the domain discrete
A natural ceiling
a pool holds 1500 gallons, a class has 30 students — the model stops applying past that
State a reasonable domain and range in context. A \$28,000 car loses 15% of its value each year: $V(t) = 28000(0.85)^t$.
Domain: $t \ge 0$, measured in years since purchase. Negative time would describe a car that did not exist yet. You might also cap it at the car's realistic lifespan.
Range: values from just above \$0 up to \$28,000. The model never reaches zero, though in reality the car eventually becomes worthless — another place the model breaks at the edges.
Both answers are stated in the language of the situation, not just as inequalities. That is what "in context" asks for.

⇄Comparing two functions given differently

A common exam setup: one function arrives as an equation, the other as a table, a graph, or a sentence, and you are asked which grows faster or which is bigger at some point. The trap is assuming you must convert one into the other's form.

You usually do not need to. Pull the key features out of each representation — initial value, rate of change or growth factor, type — and compare those directly.

Where each feature hides:

Which is bigger at $x = 6$, and which grows faster?
Function P:  $P(x) = 40x + 30$
Function Q: given by the table — $x$: 0, 1, 2, 3  →  $Q(x)$: 20, 40, 80, 160
Read Q from the table: ratios are $40/20 = 2$, $80/40 = 2$, $160/80 = 2$. Exponential with $a = 20$ and $b = 2$, so $Q(x) = 20 \cdot 2^{\,x}$.
At $x = 6$: $P(6) = 40(6) + 30 = 270$.  $Q(6) = 20 \cdot 64 = 1280$. Q is far bigger.
Which grows faster? Q — it doubles, while P adds a fixed 40. Note P starts ahead ($P(0) = 30$ against $Q(0) = 20$) and stays ahead briefly: at $x = 1$, P is 70 and Q is 40. Q overtakes between $x = 2$ and $x = 3$.
Notice nothing was converted. Both were read for their key features and compared.
Which has the greater initial value, and which the greater rate of change over $0 \le x \le 4$?
Function R:  "starts at 5 and increases by 12 each step"
Function S:  $S(x) = 3 \cdot 2^{\,x}$
Initial values: R starts at 5, S starts at $3 \cdot 2^0 = 3$. R is higher.
Average rate of change on $[0,4]$: R goes from 5 to $5 + 48 = 53$, giving $\dfrac{53-5}{4} = 12$ — the same as its step, as expected for a linear function.
S goes from 3 to 48, giving $\dfrac{48-3}{4} = 11.25$.
So R wins on that interval, narrowly. Extend to $[0,6]$ and S averages $\dfrac{192-3}{6} = 31.5$ against R's 12.
Which function "changes faster" is not a property of the function alone — it depends on the interval. Always name the interval.
